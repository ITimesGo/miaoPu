# 喵圃（miaoPu）— 3D 小岛猫咪种田设计

**日期：** 2026-09-20  
**状态：** 已确认（头脑风暴）  
**平台：** 桌面浏览器  
**技术：** Vite + React + TypeScript + React Three Fiber + drei + Zustand  

---

## 1. 产品定位

做一个浏览器端的 **斜俯视 3D 小岛生活种田** 游戏。

- **一张连续地图**：小屋、农田、小路、港口、小山、小树等同处一个世界坐标，不切场景。
- **猫咪自主活动**：玩家不操控猫；猫在岛上闲逛、休息，带来生命感。
- **日夜与四季**：光照与氛围随时间变化；季节影响作物与岛上视觉。
- **种田 + 贸易**：农田网格种植；港口作为买卖入口（后续可扩展船运/订单）。
- **参考**：成熟种田冒险（如星露谷）的「一天循环 + 资源循环」；动森式「小岛一体」的空间感。不照搬其全部系统。

### 非目标（第一期不做）

- 双场景切换（家园/农田分 Scene）
- 第三人称跟角色
- 手机/触控优先适配
- 精美写实模型与复杂动画
- 云存档、多人、深度冒险副本、复杂寻路
- 完整作物经济平衡与大量内容填充

## 2. 架构

采用 **游戏核心与画面分离**：

| 层 | 职责 | 技术 |
|---|---|---|
| Game Core | 时间、季节、农田、背包、交易、猫 AI | 纯 TypeScript + Zustand |
| Presentation | 把状态画成 3D；把点击变成意图 | R3F 场景 / zones |
| UI | HUD、商店、工具栏、时间/季节显示 | React DOM（叠在 Canvas 上） |

**原则：** 玩法逻辑不写在 `useFrame` 业务分支里；Scene 只读 store、派发 actions。


## 3. 世界与镜头

### 世界布局（同一 `WorldScene`）

| 区域 | 第一期作用 |
|---|---|
| 小屋 | 视觉锚点；睡觉推进到次日早晨；猫夜间归宿 |
| 农田 | 网格默认 6×6；锄地/播种/浇水/收获 |
| 小路 | 连接各区；猫 AI 的 waypoints |
| 港口 | 简易商店 NPC/摊位（买种子、卖作物） |
| 小山 / 小树 | 氛围与遮挡；预留后期采集 |

### 镜头

- 固定斜俯视角度（类星露谷俯视习惯）
- 允许小范围平移与缩放以看全岛
- 不跟随猫或第三人称行走

### 美术策略

第一期全部用 **简单几何体 / 色块占位**，优先验证空间与系统；模型替换不改核心 API。

## 4. 第一期竖切片玩法

在同一张岛上打通闭环：

1. 白天在农田：锄地 → 播种 → 浇水 →（时间推进）→ 收获  
2. 港口买卖：卖作物、买种子，金币循环  
3. 猫咪按行为表在岛上自主移动  
4. 日夜：光照随 `minuteOfDay` 变化；**夜晚仅改氛围，种田与商店仍可操作**  
5. 四季：切换后影响可种作物与岛配色  
6. 小屋「睡觉」：跳到次日早晨（或等价时间跳跃）  

### 内容量上限（第一期）

- 作物：1～2 种，各 2～3 个生长阶段，带可种季节标签  
- 农田：单一网格区，默认 **6×6**  
- 季节长度：默认 **每季 7 天**（可配置）  
- 经济：金币 + 种子/作物买卖  
- 猫：闲逛 / 看田 / 去港口 / 回屋睡；无数值养成深度  

### 成功标准

玩家约 5 分钟内能完成：种一轮 → 等到可收 → 港口卖掉 → 再买种子；同时能感知猫在动、日夜与换季。

## 5. 状态与数据流

### 核心状态（示意）

```
gameStore
├── time: { day, minuteOfDay, season }   // season: spring|summer|autumn|winter
├── player: { coins, inventory, selectedTool }
├── farm: { plots[][]: { soil, cropId?, stage, watered } }
├── cat: { position, behavior, targetWaypoint? }
└── ui: { shopOpen, ... }
```

### 时钟

- 可调速：现实时间驱动 `minuteOfDay`
- 跨夜 → 跨天 → `day++`
- 每固定天数（默认 7，可配置）切换 `season`
- 季节变化：更新光照/雾/植被色参数；校验新播种是否当季
- **换季时已种下的作物：继续按原生长逻辑生长至可收获**（不枯萎、不冻结）；仅禁止在非当季新播种

### 意图流

```
输入（点地块 / 点港口 / 点睡觉 / 选工具）
  → systems 校验并更新 store
  → R3F zones 与 DOM UI 订阅重绘

每 tick：
  → time.tick()
  → crops.grow()      // 依赖季节、浇水、阶段
  → cat.updateAI()     // 权重切行为 + waypoints，不做复杂寻路
```

### 猫 AI（第一期）

- 行为：`idle` | `walk` | `sleep` | `goHarbor` | `watchFarm`（可增减）
- 计时器 + 随机权重切换；沿小路预设 waypoints 移动
- 夜晚偏好回小屋 `sleep`

### 季节与作物

- 作物数据表字段含 `seasons: Season[]`
- 非当季：禁止播种（或极慢生长——第一期建议直接禁止，规则更清晰）

### 持久化

- `localStorage` 序列化 store
- 无云同步

## 6. 实现顺序（开工步骤）

| 步骤 | 内容 | 验收 |
|---|---|---|

| 7 | 季节 + 当季限制 + 配色 | 过天数可换季 |
