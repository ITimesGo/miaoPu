# 前期消耗轻度抬高 — 设计

日期：2026-10-08  
状态：已定稿（已实现）

## 范围

建筑（仓/港/船/屋）每一级金矿木知 + 建仓/修缮；商店麦种/玩具/零食/招募基价；职业升级知识每一级。

## 规则

- 金币 / 招募：`round(n × 1.25 / 5) × 5`
- 矿木知识：`max(n+1, ceil(n × 1.2))`
- 开局库存与软帽不动

## 示例

小屋 Lv2：120/4/5/8 → 150/5/6/10；种子 12→15；第二只猫基价 75→95。

## 后续：后期陡坡（2026-10-08）

建筑升级 Lv4～8 在轻度表上再乘 1.15 / 1.20 / 1.25 / 1.30 / 1.35；Lv2～3 与建仓/商店不动。  
小屋金示例：Lv4 545 … Lv8 3205。
